Engineered by subtraction.

Most app stores are a stack of servers you're asked to trust. Orion took the stack out and kept only what you can read.

  1. Database

    Ghost Branch Protocol. State lives in a self-cleaning git branch that works as a key-value store.

  2. API servers

    The menu, not the chef. Catalog headers are pre-computed static JSON, so the app reads files instead of calling an API and stays clear of rate limits.

  3. Backend logic

    Issues as a queue. Leaderboard scores and reviews travel through GitHub Issues, where anyone can see them.

  4. Trackers

    Nothing to report. No analytics and no telemetry. Threat scanning runs on your phone.

Questions people actually ask.

Answers from the developer, as they appear in the app.

Is Orion Store safe?

Orion Store is completely open source. The code is public on GitHub for anyone to audit: no hidden trackers, no data mining, just a clean gateway to apps.

Are the apps on Orion safe?

Apps are reviewed and modded by the developer using the tools on their official repositories, to make sure they're safe, functional and privacy-respecting before they land in the store.

Are the Morphe builds safe?

They're built by GitHub Actions, not patched by hand. The pipeline runs the Morphe patches against APKs from APKMirror, Uptodown and APKPure every day at 06:00 UTC, and all of it is public in Morphe-AutoBuilds.

The installation failed.

“App not installed” or “package conflicts” almost always means a signature mismatch. You can't install a modded app over the Play Store version or over a different mod. Uninstall the existing app first, then install the one from Orion.

A download isn't working.

Open the app's detail page and tap the Report icon in the top-right corner. It pre-fills an email so the link gets fixed quickly. You can also open an issue.

Will there be more apps?

As long as there are open-source or useful tools that deserve a spotlight, the library keeps growing. You can request one from inside the app and earn XP for it.

Which Android versions are supported?

Android 7.0 (API 24) and newer. Orion targets Android 15 (API 35), and the store also lists PC and TV apps.
